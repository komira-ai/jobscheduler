Early development open source, Apache 2.0

Jobs on whole hosts, and a core that places work by load.

jobscheduler is a generic scheduler for jobs and compute. A client submits a job to a server, which admits it when a host, or a machine provider of the pool, could ever serve it, and records it as queued. An agent on each host tells the server what the host offers, keeps telling it that the host is alive, and runs the container or native jobs the server places on it.

Sources: README.md, the module documentation of crates/js-lease-server/src/lib.rs and of crates/js-agent/src/lib.rs.

Install works today Linux x86_64 and arm64, and Apple silicon, from a release

$ gh release download vX.Y.Z -R komira-ai/jobscheduler -p 'js-lease-server-*-x86_64-unknown-linux-musl.tar.gz' -p SHA256SUMS

Every push to main that changes code that ships is released, with a checksum file and a build attestation. The install page has the steps, including how to verify the download.

What it does

A job, an agent, a placement core

  • A job is recorded before it is placed

    A client runs js job submit with an image pinned by digest and a wall limit above 0, and the server records the job as queued before it answers. The same id with the same job answers from the job the first submit made. js job cancel cancels a job.

  • An agent on every host

    js-agent offers the host's CPU, memory and GPUs, heartbeats, and runs container jobs on Linux (through Docker, Podman or crun) and native jobs on a Mac.

  • A whole node, quiet, when asked

    A job that needs the whole host is placed with the whole host booked, and starts when its host's agent reports the host quiet. A host that holds such a job's mark takes no other job, except as backfill.

  • Placement by measured and predicted load

    The js-sched crate admits an action to a worker when measured load plus predicted cost stays within the worker's CPU and memory. The server places jobs only under --placement js-sched, which keeps one scheduler for the life of the server and tells it of every hello and every accepted heartbeat with its load reading.

The concepts page says how each of these works and where it stops.
