Queue a native job (a program run on the host, no image) on a held lease.

The lease's host must run native jobs. The program is an absolute path, or `@bundle/<entrypoint>` with --bundle. Prints the run's id; the job's state and output are the server's, at `/v1/leases/<id>/runs`.

Usage: js lease native [OPTIONS] --program <PROGRAM> --cpu-millis <CPU_MILLIS> --memory-bytes <MEMORY_BYTES> <ID>

Arguments:
  <ID>
          The lease, as `acquire` printed it

Options:
      --program <PROGRAM>
          The program to run: an absolute path, or `@bundle/<entrypoint>` of the bundle

      --server <URL>
          The lease server, such as `https://leases.example:7300`. Plain `http://` is accepted for a loopback host only: the bearer token never crosses a network in clear. Required

      --arg <ARG>
          One argument of the program; repeat for more, in order

      --token-file <PATH>
          A file holding the bearer token: a regular file owned by you, mode 0600 or 0400. Required

      --ca-cert <PATH>
          A PEM file with the certificate to trust for `https://` (the server's, or the authority that issued it); only those certificates are trusted then. Optional: without it an `https://` server is verified against the public roots bundled in the binary, never the platform's store, because the places it is found can be redirected by the environment

      --network <NETWORK>
          The most network the job may use

          Possible values:
          - off:      None
          - loopback: The loopback interface only
          - on:       The network
          
          [default: off]

      --bundle <REF>
          The bundle the program comes from, pinned by digest: `name[:tag]@sha256:<manifest digest>`

      --json
          Print machine output (one JSON object per line, or the server's own JSON for `list`) instead of text; errors too

      --cpu-millis <CPU_MILLIS>
          CPU, in thousandths of a core

      --memory-bytes <MEMORY_BYTES>
          Memory, in bytes

      --wall <WALL>
          The longest the job may run (what the lease has left when absent)

  -h, --help
          Print help (see a summary with '-h')
