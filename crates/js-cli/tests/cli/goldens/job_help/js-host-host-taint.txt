Clears the taint a host has stored, so that placement offers the host jobs again. Operator only. It ends the taint in the server's registry and in the host's stored binding, which is written by compare-and-set as a heartbeat's clear is. A host that has no taint is left as it is and nothing is written. An unknown host is NOT_FOUND, as for a cordon. The call does not reach the agent: an agent whose marker still holds the taint refuses the next start as host-tainted, and the server takes that refusal as the host's taint again, so the operator moves the agent's marker and its owed-* records aside first, or lets the agent clear it itself.

Usage: js host host-taint [OPTIONS] --host-id <TEXT>

Options:
      --server <URL>
          The server, such as `https://jobs.example:7300`. Plain `http://` is accepted for a loopback host only: the bearer token never crosses a network in clear. Required

      --token-file <PATH>
          A file holding the bearer token: a regular file owned by you, mode 0600 or 0400. Required

      --ca-cert <PATH>
          A PEM file with the certificate to trust for `https://` (the server's, or the authority that issued it); only those certificates are trusted then. Optional: without it an `https://` server is verified against the public roots bundled in the binary, never the platform's store, because the places it is found can be redirected by the environment

      --json
          Print machine output (one JSON object per line) instead of text; errors too

      --host-id <TEXT>
          The id of the host whose stored taint to clear.

  -h, --help
          Print help (see a summary with '-h')
