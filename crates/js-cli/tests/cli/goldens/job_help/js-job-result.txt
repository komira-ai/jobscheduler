Reads the result of an ended job, for the retention window after it ended. A job that has not ended has no result, and the call is refused. Changes nothing.

Usage: js job result [OPTIONS] --job-id <TEXT>

Options:
      --server <URL>
          The server, such as `https://jobs.example:7300`. Plain `http://` is accepted for a loopback host only: the bearer token never crosses a network in clear. Required

      --token-file <PATH>
          A file holding the bearer token: a regular file owned by you, mode 0600 or 0400. Required

      --ca-cert <PATH>
          A PEM file with the certificate to trust for `https://` (the server's, or the authority that issued it); only those certificates are trusted then. Optional: without it an `https://` server is verified against the public roots bundled in the binary, never the platform's store, because the places it is found can be redirected by the environment

      --json
          Print machine output (one JSON object per line) instead of text; errors too

      --job-id <TEXT>
          The id of the ended job whose result to read.

  -h, --help
          Print help (see a summary with '-h')
