The job calls of the job service

Usage: js job [OPTIONS] <COMMAND>

Commands:
  submit  Submits a job.
  get     Reads a job: its state, its host once placed, its times and its host's silence.
  list    Lists jobs by state, label and the time they were queued, a page at a time.
  cancel  Cancels a job.
  result  Reads the result of an ended job, for the retention window after it ended.
  logs    Reads the log tail held so far, also for a running job, and for the retention window after the job ended.
  help    Print this message or the help of the given subcommand(s)

Options:
      --server <URL>       The lease server, such as `https://leases.example:7300`. Plain `http://` is accepted for a loopback host only: the bearer token never crosses a network in clear. Required
      --token-file <PATH>  A file holding the bearer token: a regular file owned by you, mode 0600 or 0400. Required
      --ca-cert <PATH>     A PEM file with the certificate to trust for `https://` (the server's, or the authority that issued it); only those certificates are trusted then. Optional: without it an `https://` server is verified against the public roots bundled in the binary, never the platform's store, because the places it is found can be redirected by the environment
      --json               Print machine output (one JSON object per line, or the server's own JSON for `list`) instead of text; errors too
  -h, --help               Print help
