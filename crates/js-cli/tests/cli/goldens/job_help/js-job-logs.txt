Reads a job's output. Without a stream: the job's state and its result's tails. With a stream: one page of that stream's bytes from an offset, read from the log store, while the job runs and for the retention window after it ended, optionally waiting a bounded time for new bytes. Changes nothing.

Usage: js job logs [OPTIONS] --job-id <TEXT>

Options:
      --server <URL>
          The lease server, such as `https://leases.example:7300`. Plain `http://` is accepted for a loopback host only: the bearer token never crosses a network in clear. Required

      --token-file <PATH>
          A file holding the bearer token: a regular file owned by you, mode 0600 or 0400. Required

      --ca-cert <PATH>
          A PEM file with the certificate to trust for `https://` (the server's, or the authority that issued it); only those certificates are trusted then. Optional: without it an `https://` server is verified against the public roots bundled in the binary, never the platform's store, because the places it is found can be redirected by the environment

      --json
          Print machine output (one JSON object per line, or the server's own JSON for `list`) instead of text; errors too

      --follow <BOOL>
          Whether to wait, up to 20 seconds, for new bytes when none are there yet, then answer; an answer at the cap has no data. Absent: false. A job that has ended answers at once.

      --from-offset <N>
          The offset of the first byte wanted, counted from the stream's first byte. Absent: 0. Past the length of an ended job's stream: refused, OUT_OF_RANGE.

      --job-id <TEXT>
          The id of the job whose output to read.

      --max-bytes <N>
          The most bytes of data in the answer. Absent: 262144 (256 KiB). A larger value than 1048576 (1 MiB) is cut to it; 0 is refused.

      --stream <NAME>
          The stream to read. Unspecified: the result's tails, and the other fields below are not read.
          
          [possible values: unspecified, stdout, stderr]

  -h, --help
          Print help (see a summary with '-h')
